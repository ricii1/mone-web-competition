Font lokal dari repositori resmi [Google Fonts](https://github.com/google/fonts):

- [Baloo 2](https://github.com/google/fonts/tree/main/ofl/baloo2), bobot variabel 400–800.
- [Nunito](https://github.com/google/fonts/tree/main/ofl/nunito), bobot variabel 200–1000.

Keduanya disubset ke karakter Latin dan tanda baca, lalu dikompresi WOFF2
dengan FontTools. Identitas font dan bobot tetap dipertahankan. Lisensi SIL Open
Font License 1.1 disertakan pada masing-masing berkas `*-OFL.txt`.
Build dan browser tidak perlu menghubungi Google Fonts.
